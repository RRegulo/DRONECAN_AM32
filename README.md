# DroneCAN для К1946ВК035

Порт ESC-узла DroneCAN (UAVCAN v0) для платы BLDC на К1946ВК035. Автор порта — **Regulo**. Плату разработала и предоставила **TDMLab** ([проект платы](https://github.com/TDMLab/K1946VK035_BLDC_BOARD)). Основная [прошивка FOC](https://github.com/vgtutf081/foc-firmware) подключает этот репозиторий как субмодуль Git.

## Состав и происхождение кода

- `src/CAN_Driver.c`, `include/CAN_Driver.h` — драйвер CAN0: PB15 (TX), PB14 (RX), трансивер TJA1042, классический CAN с 29-битным идентификатором, скорости 125/250/500/1000 кбит/с.
- `src/DroneCAN.c`, `include/DroneCAN.h` — узел ESC на libcanard. Публикует `NodeStatus` и `uavcan.equipment.esc.Status`, принимает `RawCommand` и `RPMCommand`, отвечает на `GetNodeInfo`, `RestartNode`, `param.GetSet` и `ExecuteOpcode` (SAVE/ERASE).
- `third_party/libcanard` — libcanard и сгенерированные файлы DSDL из [прошивки VESC](https://github.com/vedderb/bldc). Исходные уведомления об авторских правах и лицензии MIT сохранены в заголовках libcanard; комментарии генератора DSDL оставлены без изменений. Порт драйвера DroneCAN из VESC распространяется по GPLv3. Лицензия этого репозитория — [GPLv3](LICENSE).
- `captures/` — сохранённый сеанс Saleae и экспорт CSV со стенда. Это исходные данные измерения, а не автоматические тесты.

## Сборка

```sh
git clone --recurse-submodules https://github.com/vgtutf081/foc-firmware.git
cd foc-firmware
cmake --preset vk035
cmake --build --preset vk035
```

Рядом с `foc-firmware` также должен находиться репозиторий `dependencies`; его расположение описано в README основной прошивки. Этот репозиторий содержит исходный код порта, а не самостоятельный образ прошивки.

## Подключение к ArduPilot на стенде

При выключенном питании соедините CAN_H, CAN_L и GND разъёма CN7 с CAN-портом полётника. На плате стоит терминатор R9 сопротивлением 120 Ом. При втором терминаторе на другом конце шины между H и L без питания должно измеряться около 60 Ом. Первый обмен проверяйте без подключённого мотора.

Проверено с **MATEK H743 WING V3**, **ArduPlane 4.5.7**, Mission Planner и платой на К1946ВК035. На стенде использованы 1 Мбит/с, ID регулятора **10** и ID полётника **20**. В Mission Planner задайте `CAN_P1_DRIVER=1`, `CAN_D1_PROTOCOL=1`, `CAN_P1_BITRATE=1000000`, `CAN_D1_UC_NODE=20`, `CAN_D1_UC_ESC_BM=4`, `CAN_D1_UC_ESC_OF=0`, `SERVO3_FUNCTION=0`; затем сохраните параметры и перезагрузите полётник. Маска `4` направляет третий выход в элемент массива команд с индексом **2** (нумерация с нуля). На регуляторе задайте `can_esc_index=2`: заводское значение этого параметра — **0**. ID узлов на шине должны различаться. Остальные заводские параметры: `can_node_id=10`, `can_bitrate=1000` кбит/с, `can_raw_mode=3` (команда пересчитывается в электрические обороты), `can_timeout_ms=500`.

**Наблюдение на стенде:** ArduPilot передавал `RawCommand [0,0,4095]` с частотой около 50 Гц при отключённом моторе. Появление узла в списке не означает, что команда газа равна нулю или что реализована блокировка по состоянию armed. До подключения мотора проверьте значения команд и способ аварийного отключения. Текущий порт останавливает двигатель после таймаута команд, но пока не использует сообщение DroneCAN `ArmingStatus` как разрешение на запуск.

## Что проверено

- Внутренний самотест CAN0↔CAN1 прошёл все проверки (`0x3F`).
- На физической шине 1 Мбит/с зарегистрированы `NodeStatus`, `GetNodeInfo`, `esc.Status` и `RawCommand`. Mission Planner показал узлы 10 и 20 в состоянии Operational.
- В захвате Saleae Logic16 канал 0 подключён к CAN_H, канал 1 — к CAN_L. Декодер использовал **только канал 1** на скорости 1 Мбит/с и не вычислял разность H−L.
- При проверке через SWD счётчики подтвердили приём и передачу; потерь и отменённых передач в той сессии не наблюдалось.
- Мотор во время проверки обмена с ArduPilot **не подключался**. Реакция мотора, работа блокировки запуска, запись параметров через Mission Planner и многоузловая шина требуют отдельной проверки.

Подробности о соответствии команд и испытаниях — в [заметках основной прошивки](https://github.com/vgtutf081/foc-firmware/blob/main/plan/DRONECAN.md).
